# Student Depression Analysis Using Tableau

## Project Overview

This project analyzes the factors associated with depression among students using Tableau. It examines how academic pressure, study satisfaction, sleep duration, dietary habits, financial stress, study hours, and family history of mental illness may relate to student depression.

The project uses an interactive Tableau workbook to help users explore patterns and relationships within the dataset.

## Project File

- **Tableau Workbook:** `First Project.twbx`
- **Data Source:** `Depression_students1.csv`
- **Dataset Size:** 502 records
- **File Type:** Tableau Packaged Workbook
- **Data Storage:** Embedded Tableau Hyper Extract

Because the dataset is embedded inside the `.twbx` file, the project can be opened without downloading a separate CSV file.

## Dataset Features

| Column | Description |
|---|---|
| `Gender` | Gender of the student |
| `Age` | Age of the student |
| `Age_Group` | Age-group category |
| `Academic_Pressure` | Level of academic pressure |
| `Study_Satisfaction` | Satisfaction level with studies |
| `Study_Hours` | Number of hours spent studying |
| `Sleep_Duration` | Average sleep-duration category |
| `Dietary_Habits` | Quality of dietary habits |
| `Financial_Stress` | Level of financial stress |
| `Family_History_of_Mental_Illness` | Family history of mental illness |
| `Have_you_ever_had_suicidal_thoughts` | Reported history of suicidal thoughts |
| `Depression` | Depression status of the student |
| `index_column` | Unique record index |

## Objectives

- Analyze depression patterns among students.
- Examine the relationship between academic pressure and depression.
- Understand how financial stress affects students' mental health.
- Compare depression across different genders and age groups.
- Analyze the effect of sleep duration and dietary habits.
- Study the relationship between study satisfaction and depression.
- Identify factors that may be associated with a higher risk of depression.

## Key Analysis Areas

- Depression distribution by gender
- Depression distribution by age group
- Academic pressure versus depression
- Financial stress versus depression
- Sleep duration and mental health
- Dietary habits and depression
- Study satisfaction and study hours
- Family history of mental illness
- History of suicidal thoughts
